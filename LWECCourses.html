📊 Student monitor

"Online now" means active on the course in the last 2 minutes. Time is only counted while a student is actually using the page (it stops after 10 idle minutes).

✍️ Tests waiting to be marked

Marking a test competent opens the next module for that student. Not yet competent lets them try again. Mark against your assessor memo, which never goes on this website. Every mark is kept, with the student's answers, for their PoE pack.

🔑 Give students access

Type each student's name on its own line and press Create codes. Give each student their own code (or print the slips). A student creates their account with their code, or enters it after signing in with their Logbook account. Each code works once, for one student.

One code opens the whole qualification (FETC: Tourist Guiding, SAQA 71549). A student never needs a new code for the next unit standard: every unit standard you publish in Course setup appears for them automatically. To stop a student, or one unit standard for a student, open them in the Student monitor.

➕ Add a unit standard

Add the next unit standard of SAQA 71549 here. It stays hidden from students until you tick Students can see this unit standard below and save.

🛠️ Course setup

Give each module a title and add each file. Students only ever receive the links of modules they've unlocked. Never paste a link to an assessor memo here.

Protected files: anything uploaded here can only be opened by signed-in students of this qualification, inside the portal. Guides, presentations and tests must be PDF so students can view them without downloading (they see their name and email across every page). Videos must be .mp4 so watching is tracked. The learner answer sheet may be Word: students download it to fill in. Pasted links to other websites (OneDrive, YouTube) are not protected.
Fastest way: click 📂 Upload the whole course folder and choose the unit standard's folder (e.g. US 335815 - Conduct a guided biome experience) on your computer. The portal matches every guide, presentation, video, test and learner answer sheet to its module by the M01, M02… file names, uses the PDF versions in 06 Portal PDFs where they exist, uploads them, and saves the course. Anything in an Assessor, CONF or memo folder, and the Facilitator and Assessor Guide, is skipped automatically.
